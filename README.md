# 林星雄 · 个人网站

摄影 / 摄像 / 视频剪辑 / 新媒体运营方向的个人作品集网站。

**在线访问**：https://linxingxiong.github.io/linxingxiong/

## 简介

单页滚动式静态网站，纯 HTML / CSS / 原生 JavaScript，零依赖、零构建、无外部 CDN。

- 主页入口：`index.html`（双击即可本地预览）
- 设计语言：暖纸白底 `#F6F5F1` + 近黑 `#101010` + 朱橙强调 `#E2542C`，等宽字体英文编号 + 黑体中文，编辑式技术风
- 所有颜色集中在 `:root` 的 5 个变量（`--paper / --ink / --muted / --line / --accent`），改这几个即可换肤

## 交互效果

- 滚动自动高亮当前板块导航、内容块淡入上移
- 作品组手风琴折叠（组内互斥展开）
- 图片灯箱（点击看大图，Esc / 点空白关闭）
- 视频卡片：本地 mp4 弹窗播放，B 站作品新标签页跳转
- 人像 / 直播图组：拍立得微倾斜照片堆，悬停回正放大
- 移动端汉堡菜单 + 单列堆叠
